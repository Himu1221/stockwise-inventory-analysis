## LinkedIn draft

I built StockWise, an independent inventory analysis portfolio project using reproducible simulated retail data.

The question: how can a retailer experience stockouts and excess inventory at the same time—and what should the buyer review next?

The project connects 4,320 daily SKU observations with purchase orders, supplier promises and a budget-constrained reorder model. It includes a three-view interactive dashboard, SQL with pre-aggregation to avoid duplicate totals, automated reconciliation checks, and an editable Excel purchasing model.

One key learning: sales observed during stockouts are not the same as demand. I documented the limitations of an in-stock-day proxy and kept the planning assumptions visible.

This is a simulated case study; modeled purchase spend is not a measured business saving.
